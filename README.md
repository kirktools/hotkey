# Hotkey

轻量的原生 macOS 菜单栏快捷键工具。Swift、SwiftUI、AppKit 实现，无第三方运行时依赖，配置只保存在本机。

- 为应用绑定全局快捷键：未运行时启动，后台时显示，前台再次触发时隐藏。
- 建议统一使用 `⌘⌥` 前缀，也可录入其他组合。
- 提示内部重复、系统快捷键和全局注册冲突。
- 插件框架与功能分离：应用切换为内置插件，支持安装外部原生插件包。
- 停用外部插件会撤销快捷键并结束其进程。
- 支持配置导入、导出及上一份有效配置的恢复。

## 本地运行

需要 macOS 14 或更新系统，以及带 Swift 6 的 Xcode 或 Command Line Tools。

```sh
make dev
```

此命令退出本工作区的旧开发版，重新构建并打开 `dist/dev/Hotkey Dev.app`。开发版使用独立配置，不影响日常使用的 Hotkey。开发版应用图标带橙色 DEV 角标，菜单栏显示 DEV；日常版不带此标记。应用常驻菜单栏；后续点击菜单栏的 `⌘` 图标进入设置。

1. 在「应用」中添加本机应用。
2. 点击「录入快捷键」，例如按 `⌘⌥B`。`Esc` 取消。
3. 切到其他应用后按组合键验证，再按一次隐藏目标应用。

仅构建、测试或生成 Release 产物：

```sh
make test
make check
make build
make build CONFIG=release
make package
```

开发版和日常使用版均采用免费的 ad-hoc 签名，并检查签名有效性。`make package` 生成带版本、架构和校验清单的本地 ZIP；不提交或发布。未做 Developer ID 签名或公证，下载到其他机器后仍可能遇到系统拦截。参见[签名与更新说明](docs/signing-and-updates.md)。

## 外部插件

外部插件目前为实验功能，尚有管道背压、更新身份校验等可靠性与安全边界待完善，详见[后续工作](docs/backlog.md)。当前建议仅试用可信的本地插件。

构建同时生成 `dist/NativeMessage.hotkeyplugin`。设置 → 插件 → 添加插件，选择该包，为「显示示例窗口」录入快捷键。停用插件后，窗口与进程都会退出。

外部插件可独立构建和更新，无需重编 Hotkey，也无需另行安装一个顶层应用。只运行可信来源的插件。

参见 [插件开发](docs/plugins.md) 与 [架构及行为边界](docs/architecture.md)。

## 当前边界

- 多窗口、最小化、全部窗口已关闭、其他桌面和全屏空间的表现遵循系统与目标应用的重新打开行为；不保证恢复指定窗口。
- 无法完整枚举其他软件内部的快捷键；注册成功也不代表所有场景都无冲突。
- 第一版不申请辅助功能、输入监控或屏幕录制权限。截图能力尚未接入。
- 外部插件当前在启用时启动并握手，停用或退出宿主时退出；按需冷启动可后续优化。
- 菜单扩展、插件自定义设置字段界面、自动更新及登录时启动暂未实现。

日常配置位于 `~/Library/Application Support/Hotkey/`，开发版使用相邻的 `Hotkey-dev/`。导出配置含应用路径；插件包与构建产物不写进共享源码。

## 发布

```sh
make release-dry-run BUMP=minor
make release BUMP=minor
```

`BUMP` 支持 `patch`（默认）、`minor`、`major`；`CONFIG` 支持 `debug`（默认）、`release`。参数采用标准 Make 变量语法。

`release-dry-run` 只检查本地条件并预览版本，不联网或写入。`release` 要求干净的 `master` 与远端同步，检查、测试通过后递增版本和构建号、提交版本、创建标签并原子推送。标签触发 Actions 自动构建和发布，无需再次确认；本地只需要 Git 认证，不要求 gh 登录。普通代码推送只运行 CI。

推送失败时保留本地版本提交及标签，不自动回滚历史；修复问题后可以推送已有标签。签名身份配置和免费分发限制见[签名与更新说明](docs/signing-and-updates.md)。
