# 架构与行为

## 模块职责

| 模块 | 职责 |
| --- | --- |
| PluginSDK | 命令插件接口、清单、版本化消息、外部插件服务入口 |
| HotkeyCore | 配置校验与原子存储、命令分发、包校验、外部进程适配器 |
| HotkeyApp | 菜单栏、设置、快捷键注册、命令分发、插件装配与安装协调 |
| AppSwitchPlugin | 应用定位、启动、重新打开和前台隐藏 |
| ExamplePlugin | 独立构建的原生窗口示例 |

`HotkeyRegistrar` 仅接收绑定 ID 与键位，不了解应用。分发层根据绑定查找插件与命令。应用逻辑全部在应用插件中。当前装配入口显式接入一个内置插件，多个内置插件的发现注册可随第二个功能引入，不需要动态二进制接口。

## 应用操作

使用公开的 `NSWorkspace` 与 `NSRunningApplication`。存储 bundle ID 与用户选择的路径，路径失效后由 Launch Services 查找。运行中已有多实例时优先处理活跃实例，其他情况下优先匹配所选副本；不创建新实例。

- 已在前台：请求隐藏整个应用。
- 未在前台：取消隐藏，并走系统打开／重新打开路径。
- 未启动：启动并激活。同一应用启动期间合并重复触发。
- 多窗口：不主动抬起全部窗口，不提供窗口循环。
- 窗口最小化、全部关闭：由目标应用响应 reopen，可能只激活菜单栏，也可能恢复或新建窗口。
- 其他桌面、全屏、多显示器：尊重系统行为，不移动窗口或更改桌面设置。
- 激活请求被系统或应用拒绝时，不模拟键盘输入抢焦点。

“隐藏”与“退出”分离；快捷键不会退出应用。

## 快捷键和失败处理

使用公开的 Carbon `RegisterEventHotKey`，采用独占注册。通过 `CopySymbolicHotKeys` 检查可枚举的系统快捷键；不使用全局键盘监听。键位按虚拟键码存储，显示使用当前 ASCII 键盘布局；布局变更后物理位置保持。首次添加后用户手动录入，避免自动抢占组合。

录入只在本应用窗口捕获，录入期间暂停全部注册；失焦、关闭视图或 Esc 会恢复。替换时先注册新组合，再撤销旧组合；失败时保留旧组合。启动时单条注册失败只影响该行。暂停快捷键不终止插件任务，停用插件会终止其进程。

系统检查无法枚举全部应用内部菜单命令，独占注册也无法确认所有输入场景。当前不做不可验证的“绝对无冲突”承诺。

配置包含 `schemaVersion`；未知版本拒绝读取。保存前校验、写入采用原子替换；备份只来自有效旧文件。读取失败时阻止覆盖写入，恢复时先保留原文件。恢复与导入不会自动安装插件。

## 构建职责

- `scripts/swift.sh`：调用系统 Swift，将缓存放在 `.build`；不下载第三方依赖。
- `scripts/build.sh`：构建宿主与示例，打包本机 `.app` 和插件包，进行 ad-hoc 签名。
- `scripts/run.sh`：通过 SIGTERM 让本工作区旧进程清理退出，然后构建并打开新版本；不用 AppleScript 控制其他应用。
- `scripts/test.sh`：Swift Testing 测试，包括真实子进程测试。
- CI：运行测试并构建 Release，只提供构建产物，不发布版本。
- 正式签名、公证、下载分发：后续单独设计。

调试构建支持 `HOTKEY_DATA_DIRECTORY` 指定隔离的测试数据目录；Release 忽略此变量。构建和测试工具的沙箱选项仅影响编译子进程，不修改 macOS 安全设置或应用隐私权限。

当前脚本显式使用 SwiftPM 的 native 构建后端，以兼容部分 Command Line Tools 预览版中默认后端的测试宏加载问题。较新的工具链会提示该选项已弃用；后续在默认后端修复后移除。测试脚本只在工具链自带 Testing.framework 时补充其搜索路径，不下载测试框架。

本地已验证 Debug／Release 构建、10 项配置及真实子进程测试、原生设置窗口、示例插件安装与握手、快捷键录入、示例原生窗口，以及宿主正常退出时插件一并结束。物理键盘的全局触发、多桌面、全屏及不同应用的窗口恢复仍需按下列清单验收。CI 配置尚未在远端执行。

## 人工验收清单

自动化的配置和子进程测试不能替代桌面使用体验。需在本机验证：

1. 添加常用应用、录入 ⌘⌥ 组合，关闭设置后全局触发。
2. 目标应用未启动、后台、已隐藏、前台时分别触发；按住不应反复切换。
3. 多窗口、全部最小化、全部关闭、其他桌面和全屏状态分别记录目标应用实际行为。
4. 重复组合、系统占用、其他工具占用时失败提示明确，旧绑定仍可用。
5. 安装示例插件、绑定命令、打开窗口；停用后确认窗口及进程退出，重新启用后可用。
6. 替换不兼容插件时旧插件仍可恢复；移除并重装保留绑定。
7. 退出宿主时插件进程结束；宿主异常退出时 SDK 插件通过 EOF 退出。
8. 在临时数据目录测试损坏配置与备份恢复，不破坏日常配置。
