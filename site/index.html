01 / 快捷切换

按键到达，再按收起

应用未运行时启动；后台时显示；已在前台时隐藏。建议使用 ⌘⌥ 前缀，也支持自定义组合。

02 / 原生与本机

不必打开另一个工作台

Swift、SwiftUI 与 AppKit 构建，常驻菜单栏。配置只存本机，无账号、无统计、无追踪。

03 / 清楚的反馈

让绑定有迹可查

录入时提示内部重复、系统组合及注册冲突。支持暂停快捷键，以及配置导入、导出和备份恢复。

功能可以扩展，复杂度不必常驻。

应用切换是内置插件，也可添加外部原生插件。外部插件目前为实验功能，仅建议试用可信来源；截图功能尚未接入。

三步开始

装好。绑上。按下。

系统要求：macOS 14 或更新版本。当前下载为 Apple Silicon 原生包，尚不提供 Intel 或 Universal 构建。

  1. 下载并打开

    解压 ZIP，将 Hotkey.app 放入应用程序目录。首次打开可能遇到 macOS 安全提示，核实来源后按系统指引操作。

  2. 添加常用应用

    点击菜单栏 ⌘，进入设置，选择一个本机应用。

  3. 录入你的快捷键

    例如 ⌘⌥B；Esc 取消录入。切到其他应用后试用，再按一次隐藏目标应用。

下载前，了解这些边界。

  • 免费 ad-hoc 签名不等于 Apple 公证，其他 Mac 首次打开可能被系统拦截。不要求关闭系统安全保护。
  • 多窗口、最小化、全屏及其他桌面上的恢复遵循系统与目标应用行为，不保证恢复指定窗口。
  • 无法完整检测其他软件内部快捷键；外部插件的管道背压、更新身份校验与截图权限边界仍待完善。
  • 当前使用手动更新，无应用内自动更新；首版不申请辅助功能、输入监控或屏幕录制权限。
